
WD1 车辆解锁 × NGM v2.7（闪退修复版）
======================================

闪退根因（字节级确认）：v2.0-v2.6 的合并库里有【两个重复的车钥匙】：
  * 0x0FFFFF2C —— NGM 自带一条 Muscle_05，我又从 UCOD 加了一条同键记录
  * 0xE6B36F6A —— Speed_08 被加了两次
引擎建车辆库时撞到重复键 → 每次读档必闪退。NGM 原版没这个问题，
所以 NGM 原版一小时不闪、注入后必闪。是我的错，v2.7 已修复。

v2.7 修复
---------
* 按 key 去重：目标池已有的键一律跳过（NGM 自己的记录优先）
* 构建器加了硬断言：合并结果必须零重复键，否则拒绝输出
* 验证：74/74 目录车 ✓ 四个隐藏槽各 1 条 ✓ Speed_08 ×1 ✓
  NGM 全部 147 条新增完整保留 ✓ 池 2813 条

操作
----
1. 完全关闭游戏，data_win64 拖到 Run-Splice.cmd
   （旧库≠新库，会自动重新替换一次，几分钟）
2. 进游戏加载你的存档（NGM 要求新档，但闪退修复后旧档也应能进；
   两种都测一下最好）
3. 看叫车清单：74 辆 + 警车/疯狂车 + Muscle_05 + Speed_08
4. 成功后把工具文件夹的 ngm_diff_manifest.txt 推到 github main
   （exports 上次已给过，这次不必重传）
