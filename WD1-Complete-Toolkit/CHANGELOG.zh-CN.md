# 版本记录

## 0.3.3-alpha · 2026-09-14

- 分离未安装/未触发/缓冲不可读/指针不合格/不稳定/2秒过期等捕获状态，并在界面与报告中显示计数和样本年龄。
- 详情自动更新；暂停后的原始样本缓存只供核对，不读取或写入旧对象。
- 持续开关可预置等待同对象新心跳；增加/减少独立排队一次，30秒取消、禁止重复提交。写入仍保留2秒新鲜度、稳定性、同对象/代次与授权检查。
- 对象/范围/代码改变、STOP、授权过期取消排队；异常不自动重试增量。
- 新增39项捕获/暂停/排队模拟检查；框架引用728项、缺失0。原生签名、Lua与全部功能计划未改，用户Windows捕获效果仍待诊断。

## 0.3.2-alpha · 2026-09-14

- 修复扫描器将模块报告尺寸、节范围和64MiB预算混为统一错误的处理方式；用户实际触发数值仍须新版诊断确认。
- 校验磁盘PE头并比对运行时头，按VirtualQueryEx同映像页面分块读取；不扫描任意进程内存、不取消边界。
- 块边界重叠/地址去重，补丁范围统一到实际扫描过的代码；不完整扫描禁止全部捕获/写入。
- 连接失败也可导出诊断，释放失败连接句柄；不再要求用户反复重选正确目录。
- 新增48项扫描回归；保留0.3.1微软net48构建修复。功能范围与Lua插件不变，仍无用户Windows修复后实测。

## 0.3.1-alpha · 2026-09-14

- 修复打开独立参数面板时的 `String.Split(Char, StringSplitOptions)` 缺失方法：产品4处调用改用显式 char[] 重载。
- 强制微软 .NET Framework 4.8 参考程序集构建，禁用默认/Mono框架引用；加入目标框架属性和最终EXE成员引用审计。
- 对旧EXE复核定位到1项缺失引用；新EXE607项框架引用均可解析，文件/原生模拟/Lua回归和两窗口冒烟再次通过。
- 只修复桌面兼容性：插件、计划、功能范围与原存档/配置位置不变，无需重新安装游戏插件。仍未在用户Windows修复后实测。

## 0.3.0-alpha · 2026-09-14

- 按用户纠正：成就=游戏内进度系统。移除旧平台成就窗口、独立EXE、桥接DLL、源码与依赖数据。
- 完整计划写入项目：169条独立控件/需求记录，另保留142条既有玩法/保护验收。未绑定项不删除，不用可点击假开关冒充。
- 无限与增加分别保留。新增无限库存资源候选，与一次增加材料/消耗品分开；明确公共路径含备弹，未冒充每种材料独立锁定。
- 原创原生参数引擎与24个候选控件：只读扫描、原字节门槛、临时捕获、稳定/新鲜对象、数值范围、独立维持/增减、模式切换、代码恢复、报告。
- 中文原生面板加入搜索、收藏、独立开关/状态、单次输入、热键与冲突提示。启动不恢复任何已开启效果。
- Lua全武器/全衣服/全物品为三个独立批次；白名单扩展218键，加入五套数字之旅服装与Golden D50候选；按模式过滤，不混入技能/经验奖励。
- 保留无限弹药，同时增加独立单次弹药补给；单项材料/消耗品有数量输入。
- 验证：47项文件核心、51项原生模拟进程、335个Lua断言；两个窗口Linux/Mono/Xvfb冒烟。无真实Windows游戏测试，不是最终完整版。
