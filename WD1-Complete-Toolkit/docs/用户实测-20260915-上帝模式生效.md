# 用户实测 — 2026-09-15：上帝模式生效（v0.4.0 / UI4）

## 用户原话（回报）

> 实测回报，开启了 god mode 大电箱面对面都炸不死（这个是必死）

## 判定

**lua.god 首次真实游戏验证通过。** "大电箱面对面爆炸"是脚本性必死危害，玩家存活说明效果真实生效，不是巧合或显示问题。

## 这次测试实际证明了什么

1. **UI4 插件确实装上并载入了。** 旧 UI2 的回调在用户机器上是全死的（上一轮实测），同一套文件不可能突然驱动出无敌效果；只有 0.4.0 的无条件重绑 + 轮询兜底能解释这个结果。
2. **ARM 单机门槛正常放行**（未 ARM 时勾选会被拒绝并弹回）。
3. **命令状态读取 + 轮询/回调链路生效**（勾选框被翻译成游戏调用）。
4. **`ActivateInvincibility(玩家实体)` 在 build 11241563 上有效。**
5. **OnUpdate 每帧重申无敌在重度危害下持续有效**（效果没有在爆炸瞬间丢失）。

## 这次测试没有证明什么（不要外推）

- 无限弹药 / 无限专注 / 关闭警网：同一路径，但**未测**。
- 解锁批次（技能点、金钱、罪恶值奖励、全武器等 AddItem 路径）：**未测**，与无敌代码路径不同。
- 无敌本身是**会话效果**：不存档、不持久；取消勾选或 STOP 即还原。重启后仍无敌才是异常。
- 是按钮回调还是轮询兜底在干活：PING 的 Clicks 计数未回报，无法区分。两者都已可用，不影响使用。

## 下一步建议（按风险从小到大）

1. 01 分类点 [PING]，看 Clicks 是否 +1（区分回调/轮询路径，一条信息即可）。
2. 勾选 Infinite Ammo / Infinite Focus，各验证几分钟。
3. 03 分类：`point_value=1` → Prepare normal Skill Point reward → CONFIRM → 打开技能页看是否 +1（持久路径，需要备份回执；先测 +1）。
4. 07 分类：先单勾一个罪恶值/任务XP 奖励物品 → CONFIRM → 到对应界面核对；正常存档并重启游戏，验证持久性后再考虑批量。
5. 批量（[ALL PROGRESSION] 等）放在单项验证之后；CONFIRM 后每 4 帧提交 1 项，数量大需要等待。
