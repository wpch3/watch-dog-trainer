# 使用指引（v0.4.21）—— 手把手版

> 配合 0.4.21 使用。

## 0. 先分清两套系统

| | 桌面 EXE 原生面板 | 游戏内 Lua 菜单（UI4） |
|---|---|---|
| 需要宿主？ | 不需要 | 需要 NexusTools |
| 已验证 | **无限电池 ✅ 加金钱 ✅** | **无敌 God ✅** |
| 包含功能 | 24 个候选（金钱/技能/经验/电池/声誉/通缉/库存/计时…） | 无敌/弹药/专注/警网 + 2709 条解锁目录 + 技能点/金钱 |

两套互相独立，不要同时改同一个数值。

## 1. 每次开玩前的一条龙（只有第 1 步在桌面做）

1. **完全退出游戏**
2. 开 `WD1-Toolkit.exe` → 存档与恢复 → **备份**（选真实存档目录）
3. 01 安装与启动 → **安装 / 更新游戏插件**（用刚才的备份）
   → 这一步把"**2 小时授权回执**"写进插件。没这步，弹药/物品/技能点/金钱都会被拒（见第 2 节）
4. 进游戏，正常进入自由探索，打开宿主菜单 → 确认标题 **WD1 KIT - Main [UI4]**
5. 进 `01 / Safety and Report`，**勾选 `[ARM]`**（点动式：勾上立即执行并自动弹回）
   → 成功标志：游戏内弹出 "Single-player test armed"，面板 Armed=true

> 提示：游戏每次暂停（开暂停菜单/切出）都会自动停止全部效果，这是安全设计。回来后**重新勾一次 [ARM]** 即可。

## 2. 提示码对照表（看到 WD1KIT: XXX 就查这里）

| 通知显示 | 意思 | 怎么办 |
|---|---|---|
| `NOT_ARMED` | 没激活 | 去勾 `[ARM]` |
| `PAUSED` | 游戏暂停过 | 关掉暂停界面，重新勾 `[ARM]` |

| `ENTITY_CHANGED` | 换角色了 | 重新勾 `[ARM]` |
| `BACKUP_TICKET_INVALID` | **2小时授权过期/缺失** | 退出游戏 → 重做第 1 节的 备份+安装 → 2小时内完成操作 |
| `API_MISSING` / `CALL_FAILED` | 你的构建缺这个接口 | 停止使用该功能，把提示原文发我 |

（无敌 God 不需要回执；**弹药/物品/技能点/金钱需要回执**——它们会写进存档。）

## 3. 无敌 / 弹药 / 专注 —— 只用勾选框

- **勾上 = 开，取消 = 关**，立即生效，不用按别的按钮
- 无敌已实测。弹药/专注勾上后被弹回 → 看通知提示码，照第 2 节处理
- 勾了完全没动静且不弹回 → 点 `[STATUS]`，通知里会显示 `clicks/polls/armed/core` 各数值，把那一行发我

## 4a. 技能点/经验 —— ✅ 已实测通过（+1 与 +500 均生效且重启持久），按下面步骤可重复使用

**走错窗口是一直没效果的最常见原因。** 你有两个完全不同的工具，长这样：

| | 游戏内菜单（NexusTools） | 桌面原生面板 |
|---|---|---|
| 怎么打开 | 游戏里按 Insert / Pause 呼出 | 双击 **WD1-Toolkit.exe** → "游戏内参数"页 → 打开独立参数控制面板 |
| 长什么样 | 黑底 ASCII 英文列表 | 中文 Windows 窗口（搜索框+列表+按钮） |
| 独有字样 | 消息出现 **Prepared / [CONFIRM]** | 按钮叫 **"捕获所选对象 / 排队一次增减"** |
| 加技能点 | ❌ 只有"物品"，无效 | ✅ **"增加普通技能点"** 直接改数值 |

**判断口诀：消息里看到 Prepared 或 CONFIRM = 走错窗口了。**

正确步骤（和你加钱成功那次完全一样的流程，只换按钮和触发方式）：

1. 游戏开着、进单机自由探索；桌面上 WD1-Toolkit.exe → 游戏内参数 → 打开独立参数控制面板
2. 点 **只读连接 / 扫描**（每次开机一次；这次会话你已扫描过就跳过）
3. 列表里选中 **"增加普通技能点"** 这一行 → 点 **"捕获所选对象"**
4. 切回游戏，**打开一次技能页**（让游戏读资源对象，产生心跳）
5. 回面板等该行状态变 新鲜/稳定；**先核对原始值=你当前技能点数**（对不上就是抓错对象，别写入，重新捕获）
6. 数量框填 **1** → 点 **"排队一次增减"** → 弹窗点确定
7. 切回游戏**再打开一次技能页**（触发写入）→ 打开技能页核对 +1
8. 成了之后同一捕获下：选 **"增加普通经验"** 行，数量 500，同法排队+触发
9. 两个都成了 → **正常存档 → 完全退出 → 重启** 确认持久

注意：持久写入需要 2 小时内的备份授权（装插件时那份备份就是授权）；过期就重新备份+安装。30 秒无心跳排队会自动取消——动作慢点没关系，重新排队即可。

## 5. 罪恶值 / 任务XP 奖励（07 页，一步一步来）

这个页面就是"**点一个奖励 → 点 CONFIRM**"两步：

1. 完成第 1 节（ARM + 新回执）
2. 进 `07 / Progression Rewards`
3. 页面**顶部**有 `[CONFIRM]` 和 `[CANCEL]`（等下要用，注意位置）
4. 往下找到折叠组，例如 **"Notoriety and Online Rewards (32)"**（罪恶值/线上奖励），点开它
5. 点里面**任意一个条目**（点一个就够，别多点）
   → 通知：`Prepared: 1 entries, each 1. Press [CONFIRM] to grant...`
6. 点第 3 步记住的**页顶 `[CONFIRM]`**
   → 通知：`BATCH_STARTED`，然后 `BATCH_SUBMITTED_NOT_VERIFIED`
7. 回游戏核对：任务XP类→看经验/等级；罪恶值奖励武器→看武器是否入手；现金类→看钱包
8. 核对无误 → 正常存档 → 完全退出 → 重启确认还在（持久性验证）
9. 单项都稳了，才用大按钮 **[ALL PROGRESSION]**（一次准备全部进度奖励，CONFIRM 后约半分钟逐项提交，期间别暂停游戏）

## 6. 原生面板：捕获到底要做多少次？（你问的"能不能跳过"）

**不能全跳过，但远比你以为的少。** 记住两句话：**一次捕获管一片，管一次开机。**

| 操作 | 频率 |
|---|---|
| 连接 + 扫描 | 每次开机游戏 **1 次**（之后所有功能共用，不用重复） |
| 捕获【钱包】 | 每次开机 **1 次** → 同时解锁：加金钱、加技能点、加经验、无限金钱 |
| 捕获【电池】 | 每次开机 **1 次** → 无限电池 |
| 捕获【车辆】 | 每次开机 **1 次**（开车状态抓）→ 车辆生命锁定 |
| 增减/开关 | 2 小时内、对象不变时 **随便用，不用重新捕获** |

需要重新捕获只有三种情况：**重启游戏后、换角色后、换车后要用车功能**。

为什么不能完全去掉：引擎靠"这个数在变、别的都不变"来认准"这是你的钱包/你的车"，跳过这一步就可能写到 NPC 或别人车上——这是写内存的安全底线，砍掉它早晚会坏档。
