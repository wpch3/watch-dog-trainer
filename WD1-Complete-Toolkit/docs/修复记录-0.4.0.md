# 0.4.0：按钮无反应根因修复（UI4）+ 全解锁目录

## 你上一轮实测的现象

菜单是 UI2；按钮不缺、00 出现、无 UI ERROR；但点 ARM / God Mode / STATUS / CONFIRM 全部毫无反应——没有"确认激活界面"、没有"开启无敌请求"提示，STATUS 也不显示任何东西；实测无敌不生效。

## 根因（三件叠在一起）

### 根因一：UI3 从来没有真正交付过（为什么你看到的仍是 UI2）

上一版把 UI3 只写进了 `src/Plugin/menu.lua`，**没有同步到 `payload/`**，而桌面程序安装插件时只复制 `payload/`（`Files.Install` → `BaseDirectory/payload`）。当时产出的 ZIP 里也全是旧文件。所以无论你怎么"安装/更新游戏插件"，装进去的永远是 UI2。

### 根因二：命令注册会跨重启持久化，回调却丢了（为什么按钮全是死的）

NexusTools 官方文档明确：**Commands cannot currently be unregistered / 命令状态跨游戏重启持久化**。官方 Trainer 的做法是每次载入后**无条件**调用 `SH_Commands_RegisterCallback(id, cb)` 重新绑定回调（源码注释"Allow hotreloading"）。旧 UI2 把 `RegisterCallback` 放在 `Register` 之后的**同一个 pcall 里**——一旦旧会话已注册过同名命令导致 Register 出错，**回调绑定整段被跳过**，按钮从此挂在死回调上：点了什么都不发生，也没有任何错误显示。

### 根因三：持续功能完全依赖回调，没有不依赖回调的兜底

官方 Trainer 的无敌**根本不靠按钮回调**：它用 Script 的 `OnUpdate` 每帧轮询 `SH_Commands_GetStateBool`，勾选框状态一变就生效。旧 UI2 没有这条路径，回调一死，无敌就永远开不起来；面板里也没有任何计数器能区分"点击没送达"和"点击被门槛拦下"。

## UI4 的修复

1. **payload/ 与 src/Plugin 字节一致**（验证器强制断言），并打入新 ZIP。菜单标题 **`WD1 KIT - Main [UI4]`**——看不到 [UI4] 就是没装上新插件，不要再测无敌。
2. **无条件重绑回调**：每个命令注册后，单独 pcall 调用 `SH_Commands_RegisterCallback(id, cb)`，Register 失败（命令已存在）不再影响回调绑定。无回调型 int 输入除外。
3. **轮询兜底（官方 Watcher 模式）**：Script OnUpdate 每帧轮询所有开关命令状态。**就算所有按钮回调全部失灵，你仍然可以只靠勾选框完成一切操作**：
   - God / Ammo / Focus / Police：勾上即生效（每帧维持，与官方 Trainer 相同），取消即还原；未 ARM 时勾选会被拒绝并自动弹回，面板 Error 列显示原因。
   - ARM / STOP / CONFIRM / CANCEL / REPORT：改成**点动式勾选框**——勾一次执行一次并自动复位。
4. **单次执行去重**：回调与轮询汇聚到同一个 `WD1KIT_UI4_MOMENT` 入口，fired 标记保证一次用户动作只执行一次（测试锁定：一次点击恰好一条 UI4_ENTER）。
5. **面板内诊断**：每页头部显示 `Clicks / Updates / Loads / Polls / Alive / Paused / Armed / God / Ammo / Focus / Police / Last / Core / Error`。PING 一下 Clicks 不涨=回调链路断（此时用勾选框）；涨了但 Error 显示 NOT_ARMED=先 ARM。
6. **loadstring 缺失不再炸整个菜单**：宿主沙箱如果没有 loadstring，自动退化为普通闭包回调并在日志记录 `UI4_THUNK_FALLBACK`。

## 最短验证顺序

1. 退出游戏 → 用新包"安装 / 更新游戏插件" → 完整重启游戏。
2. 打开菜单，**确认标题是 `WD1 KIT - Main [UI4]`**。还是 UI2 = 没装上，直接反馈，不要继续。
3. 进入 01 / Safety and Report，点 `[PING]`：面板 Clicks 应 +1。
4. 勾选 `[ARM]`（点动，自动复位）：面板 Armed=true，游戏内弹出 "Single-player test armed"。
5. 勾选 God Mode 复选框：面板 God=true；回游戏受击验证；取消勾选还原。
6. 若 Clicks 始终为 0：说明宿主不调用任何回调——没关系，勾选框路径仍然全部可用；请把面板上 Polls/Updates 数值告知即可。

## 仍然成立的边界

- 全部仍是**候选实现，未在你的真实游戏里验收**；`AddItem` 的永久性/衣柜可用性/叫车目录可用性要逐类验证。
- 奖励物品**不重写**任务完成计数、在线胜场、服务器战绩；罪恶值本身没有已证实的直接数值接口，本版通过其奖励物品路径本地授予。
- 持久写入仍需有效备份回执（2 小时内）；ARM 仍是手动单机确认；联机/入侵/竞速中禁止使用。
