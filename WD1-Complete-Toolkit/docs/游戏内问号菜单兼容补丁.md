# 游戏内问号菜单：ASCII兼容文字补丁

## 目前确认的事实

- 用户已看到本项目 WD1 KIT 菜单，但中文显示为问号。
- 原 `menu.lua`、`core.lua`、`catalog.lua` 和发行payload都可以严格按UTF-8解码；没有坏编码字节。
- 仅凭问号无法分辨宿主缺字、字体范围、字符转换或缓存标签问题，不能断言游戏语言/目录不对。
- NexusTools官方1.1.12变更记录包含简体中文菜单文字渲染修复；这证明宿主存在中文渲染相关处理，但不证明用户当前自定义Lua标签已正确显示。[1](https://www.nexusmods.com/watchdogs/mods/491)

可以先核对宿主实际版本是否1.1.12，以及宿主自己的语言选项是否为Chinese Simplified/简体中文；完整退出并重启后再看。没有核实宿主配置路径，不提供猜测的改INI/替换字体DLL操作，也不要求更改Windows区域、游戏语言或关闭防护。

## 临时兼容方案

游戏内标签/描述/通知/目录显示名全部使用ASCII英文，附中文对照；桌面程序继续中文。

- 修改68个界面字符串和218个物品显示名。
- 不改变功能键、命令ID、调用参数、游戏数据ID、模式过滤、开关默认值、备份回执或游戏逻辑。
- 无敌仍通过同一 ActivateInvincibility/RemoveInvincibility 路线；读到菜单不等于无敌已经实测。
- 全武器/全衣服/全物品与无限/增加仍分别保留，绝非简化成只有无敌。
- 中文菜单源文件保留在 `locales/zh-CN/Plugin`，并未永久放弃中文。待宿主字体/字符链路核实后可恢复。

## 推荐安装方法：更新工具payload，再由工具安装

1. 正常退出游戏；若原生面板仍有捕获/补丁，先安全断开。
2. 把补丁里的 **`payload` 文件夹**合并到你运行 `WD1-Toolkit.exe` 的工具文件夹，允许覆盖对应Lua文件。**不是这一步直接解压到游戏根目录。**
3. 打开原来的工具，使用有效的当前存档备份；到“01 安装与启动”点击“安装 / 更新游戏插件”。若回执过期或源存档变化，按提示重新备份。不要只替换payload后就以为游戏内文件已更新。
4. 完整重启游戏，按Insert进入宿主。应看到 `WD1 KIT - Main [TEST]` 或 `WD1 KIT - Bad Blood [TEST]`。
5. 选择 `02 / Player and Police` → `[ARM] I am offline and in single-player free roam` → `God Mode`。

本补丁**没有EXE**，不需要换桌面程序或重装游戏。不要混合放入其他原版资源包。

## 首轮只验证

- 英文菜单是否可读；
- God Mode开启是否有效，关闭是否恢复正常受伤；
- 测完用STOP，不全开或批量授予物品。

若英语仍变问号，说明并不只是中文字形缺失。请说明是否连 `God Mode` / `ARM` 等ASCII文字也如此；不需要重复买东西或更换站位。

- 全部运行菜单/通知/显示名仅含ASCII。
- 对字符串常量屏蔽后，core/menu代码结构与原中文版本完全一致。
- 218个物品的id/key/name/group/mode逐字段保持一致。
- 原335项Lua断言通过；新增界面文本/目录/回调检查通过（1895个断言含逐条显示文字检查，不是功能数量）。
- 默认无游戏写入；原命令ID、无敌回调、STOP和备份门槛不变。
- 没有在用户的NexusTools窗口实际渲染确认，也没有因此认证任何新增游戏行为。
