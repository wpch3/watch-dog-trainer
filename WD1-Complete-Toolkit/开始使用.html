01 / 先只读扫描，最快判断可适配项

  1. 整个包独立解压，不要覆盖旧目录。打开 WD1-Toolkit.exe。
  2. 选择真实游戏根目录，正常进入单机游戏。
  3. 游戏内参数 → 打开独立参数控制面板 → 只读连接 / 扫描。
  4. 点击“导出诊断（失败也可）”保存 WD1-Native-Probe.json。连接失败也能导出；这一阶段不改代码/数值，无需 CE 或宿主。

02 / 使用原生独立开关

  1. 先保存、退出游戏，在管理工具手选真实存档并校验备份。之前报告没有找到存档，不代表备份完成。
  2. 重新进游戏，打开参数面板，确认单机与实际活动。
  3. 数值项先“捕获所选对象”，回游戏触发菜单/活动，查看执行次数/状态并核对原始值；暂停后的缓存只供查看，不用抢2秒。
  4. 无限/冻结勾选对应行；增加/减少选中行填数值，按“排队一次增减”，等待同一对象的新心跳；30秒无刷新自动取消。增加不会开启无限。
  5. 切换活动前停止全部；退出面板前恢复代码并断开。
捕获会安装临时跳转，不再是纯只读扫描。手选模式不是自动识别；对象稳定也不证明属于玩家。首轮一项一项验证。

03 / 游戏内 Lua 菜单

独立安装作者 NexusTools ≥1.1.12，关闭游戏后用管理工具安装本项目插件；本体 / Bad Blood 完全退出后切换。按 Insert / Pause / Ctrl+\ → WD1 KIT → ARM。

无敌、持续弹药/专注、单次弹药、单项材料增加、全武器/全衣服/全物品批次分别控制。批次先“准备”，再 CONFIRM；STOP不回收已写入的奖励。

给予物品不等于永久拥有、叫车可用或游戏内任务完成；需正常存档后重启核验。

安全与反馈

备份常见位置是 Ubisoft Connect 安装目录 savegames\账号\541；手选实际 .save/.save.*/.sav 文件夹，别选 GamerProfile.xml。备份保存在本机工具数据目录，不自动上传。

工具异常退出、无法恢复代码时，完全退出游戏再重启。没有代码签名，不要求关闭安全软件、UAC或防火墙。恢复文件成功不证明游戏可读档。

无需截图、密码、完整存档或内存转储；使用脱敏候选报告和口述数字前后反馈。
