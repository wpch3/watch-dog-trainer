UI2 菜单完整显示与备用控制

这是菜单层修复，不改桌面EXE、原生加钱或游戏动作核心。具体宿主异常尚未获得，不声称已在你的游戏中验证成功。

本轮只测无敌：
进入 00 / Quick Controls → ARM → God Mode ON → STATUS。
关闭用 God Mode OFF 或 STOP。无敌仍要观察普通伤害开/关效果，不以按钮状态充当效果证明。
英文文字中文含义
WD1 KIT - Main [UI2]新版本本体菜单；必须看到UI2标记
00 / Quick Controls独立快速控制，不经过复杂布局/复选框
[ARM] Offline free-roam test确认仅单机自由探索，激活本次测试
God Mode ON开启无敌请求
God Mode OFF关闭无敌
[STATUS] Show armed / god / script显示armed/god/script状态，帮助判断按钮是否执行
[STOP] Disable tool effects关闭本工具持续效果与队列
02 / Player and Police仍保留普通ARM、God ON/OFF以及复选框等完整控制
[UI ERROR: ...]某个可选控件创建失败；不应再静默截断整页

若00未出现，检查02内的普通ON/OFF按钮。若仍是旧ASCII MENU标题和STOP，先核对新menu.lua是否通过工具安装到了游戏，并完整重启。

若UI2已经出现但仍缺控件，只需说明00有无及UI ERROR文字；可用宿主日志的[WD1KIT] UI2_行，无需截图或完整日志。
