## 1. 文件与计划

- **`WD1-Toolkit.exe`**：唯一桌面程序，x64 / .NET Framework 4.8 系列；不用额外安装 CE。
- **`完整计划.html`**：可搜索的完整功能表，169 个独立控件/需求记录；不是“+169 已可用修改器”。
- **`plan/用户确认的完整计划.md`**：用户约束与完整计划，后续继续以此为准，不能删掉未完成项。
- `plan/original_gameplay_requirements.json`：保留原 150 项中剔除平台成就专属范围后的 142 条游戏玩法/保护验收，防止合并大类时漏掉细项。

- `开始使用.html`、`docs/`、`src/`、`tests/`：操作、证据、源码和实际测试记录。

## 2. 本轮真正新增的代码

### 原生参数面板（不需要宿主）

在“游戏内参数”页打开。**24 个独立候选控件**，每个有自己的状态、错误和操作，部分为一次性按钮而不是循环开关。

- 无限金钱（维持最低余额），与增加金钱独立。
- 普通技能点最低值、增加普通技能点、增加普通经验。**不把普通技能点当蜘蛛/疯狂/孤独技能点。**
- 无限电池（使用容量/当前电量字段）。
- 载具生命锁定、蜘蛛坦克能量维持。
- 声誉增加、减少、好声誉 +600、坏名声 -600，互斥锁定。
- 消除当前通缉、增加/减少热度、锁定无通缉、无警方侦测，彼此区分。
- **无限库存资源**：公共库存扣减保护，包含材料/道具/备弹；与“增加资源”完全独立。**不是仅材料专用的开关**，按每一种材料分别无限的路径仍待绑定。
- 无需换弹、任务潜行候选、无限黑客计时器。
- 饮酒计时冻结的两处候选路径。
- 蜘蛛坦克/疯狂计时冻结：两个独立控件，共用当前数字之旅计时器的候选解析器；手选模式、切换先停全部，**并非已经证明两个活动分别自动识别成功**。
- 搜索、收藏、逐项快捷键、单项停止/总停止、当前原始值回读、候选报告。

签名与字段来自有来源记录的公开 WD1 表，见 `docs/原生接口证据.md`。只有用户构建的三个文件指纹一致、进程路径一致、可执行节中的签名唯一且原字节一致，才允许启用。**观察目标 build 11241563 不等于“已验证支持”。**

## 3. 最短测试顺序

### A. 原生面板可先只读探测

1. 完整解压，运行 `WD1-Toolkit.exe`，选真实游戏根目录（含 bin / data_win64）。
2. 正常启动你的 WD1 并进入单机场景。“游戏内参数” → **打开独立参数控制面板**。
3. 点 **只读连接 / 扫描**。这一步不修改进程代码或游戏数据，不需要先安装宿主。
4. 无论连接成功或失败，都可点 **“导出诊断（失败也可）”** 保存 **`WD1-Native-Probe.json`**。它只含候选命中数、相对位置、状态等，不是内存转储或存档。

### B. 真正启用前必须先备份

1. 正常保存并退出游戏。“存档与恢复”选择真实的 WD1 `.save` / `.save.*` / `.sav` 文件夹，校验备份。
2. 你的旧报告 `saves` 为空，**不代表没有存档，更不代表已备份**。常见 Steam 版路径为 Ubisoft Connect 安装目录 `savegames\账号\541`，另一个候选为 `274`；不要选 GamerProfile.xml 或账号父目录。
3. 再进游戏，重新打开参数面板，并勾选单机确认。备份授权两小时内有效；不能把备份别的账号/档案当成当前档案。
4. 按真实活动选择模式。**这个模式是你的选择，不是自动游戏识别。**
5. 数值功能先选中行 → **捕获所选对象** → 回游戏打开钱包/技能页、开车、进入相应活动等 → 等待新鲜、稳定对象 → 核对原始值。
6. 持续功能勾选该行；一次性增加/减少选中行，输入数量后点 **排队一次增减**。请求绑定当前对象，待确认之后的新心跳才执行；30秒无刷新自动取消，可手动取消。一次性操作不会自动开启无限功能；同字段锁定开着时，先关闭锁定再增加。
7. 首轮一次只测试一项，并通过游戏里的数字/行为核对，正常存档、重启再检验持久性。

### 捕获不是“完全只读”

**扫描是只读；点击“捕获”会在已验证候选指令处安装临时跳转，把对象地址/心跳记录到游戏进程自己的缓冲区。** 捕获本身不改该游戏资源值，但已经涉及代码修改，可能与宿主/其他修改器冲突，也可能失败或崩溃。

- 写代码前短暂暂停游戏进程、检查线程指令位置；无法安全写入就拒绝，不自动强行覆盖。
- 对象变化就停止对应维持；捕获过期时不继续写旧对象。不能证明稳定对象一定属于你，尤其是载具；先观察，离车/换活动前先停止。
- 不使用内核驱动、不结束游戏进程、不更改防护设置、不自动提权。
- 不要与别的修改器同时修改相同字段/指令，也不要和 Lua 的同类维持同时开启。
- 关闭窗口前会尝试恢复原代码；忙于目标代码时可能要求稍后重试。**工具异常关闭或无法恢复时，必须彻底退出游戏再重启。**
- 分配的少量捕获缓冲区保留到游戏退出，避免旧线程仍在使用时释放；关闭修改不代表回收已写入的资源或回退存档。

1. 按作者说明单独安装 **NexusTools ≥1.1.12**：https://www.kaverti.com/en/TroploNexusTools/Home 。核心不随本包分发，实际兼容性尚未验证。

4. 无限弹药和单次补给分别控制；资源增加可填数量；全武器/全衣服/全物品先准备，再 CONFIRM。CANCEL / STOP 取消队列/关闭持续效果。

## 5. 保护与恢复

备份仅支持上述文件类型/数量/大小范围；回执不是密码学签名、不识别当前加载的存档。恢复需退出游戏与 Ubisoft Connect，先另存当前副本，再恢复到原目录；云同步冲突由你确认。文件哈希成功不证明游戏能正常读档。
